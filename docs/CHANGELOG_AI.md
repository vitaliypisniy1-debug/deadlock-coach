# Deadlock Coach — журнал изменений с участием ИИ

- **0.17.0 (13.11.2026).** Версия поднята для выпуска сборки из PR #14 (дизайн, «Тренер», «Ошибки», справочник). Выпуск запрошен владельцем. Перед выпуском: `npm test` — 86 тестов. Результат релизной сборки GitHub Actions и локальной сборки установщика см. в записи об итоге выпуска.

- **Промежуточная сборка `release/all-sections` (13.11.2026, версия не повышалась, 0.16.2).** Объединены четыре ветки: `design/redesign` (новый вид, `docs/DESIGN_SYSTEM.md`), `coach/rework` (переработанный «Тренер», динамика, достижения, блок на Главной), `errors/audit` (аудит правил, наблюдения, нормы по герою/рангу/роли, исправление ранга при нулевом badge) и `codex-counters/deep-analysis` (справочник контрпредметов по угрозам героев). Конфликты были в `src/core/coach.js`, `src/main/sync.js` (оба разрешены вручную) и в документах (сохранены обе записи). Проверено: `npm test` — 86 тестов; запуск из исходников на копии профиля, 10 разделов без ошибок консоли (CDP), скриншоты просмотрены. Не проверено: `npm run dist` и собранная версия, минимальный размер окна, блок «Наблюдения» целиком, роли по героям в интерфейсе (нужна заявка дизайну). Запись об объединении добавлена координатором.
- **0.16.2.** В разделе «Перед игрой» добавлены пометки о малой выборке и интервал неопределённости. Прошли 68 тестов и сборка Windows. В собранном окне на временном профиле подтверждена нейтральная пометка для пары с одной сохранённой игрой.

Журнал описывает значимые задачи, их статус и результаты проверок. Записи Git подтверждают наличие изменений. Авторство ИИ и ручные проверки указываются, когда они известны из рабочей истории.
