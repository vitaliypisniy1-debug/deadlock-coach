# Дизайн-система «Ночной город»

Единственный исполнитель внешнего вида — сессия редизайна (ветка `design/redesign`). Остальные потоки стили, вёрстку и навигацию не меняют: присылают описание того, что показать (блоки, поля, порядок, состояния), а оформление делается здесь. Источник вдохновения — сайт playdeadlock.com/cityneversleeps (бирюзово-чёрный фон, оранжевый акцент).

Файлы: `src/renderer/theme.css` (всё оформление, лежит поверх `styles.css`), `fx.js` (анимации), `icons.js` + `vendor/` (иконки Lucide, GSAP), `fonts.css` + `assets/fonts/` (Alegreya SC и Jost), `overlay.css` (оверлей). Происхождение и лицензии: `src/renderer/vendor/README.md`.

## Токены (`:root` в `theme.css`)

| Назначение | Токен |
|---|---|
| Фон, поверхности | `--bg` `--bg-2` `--panel` `--panel-2` `--panel-3`, стекло `--glass`, кромка `--edge` |
| Текст | `--text` `--text-2` `--muted` `--dim` |
| Акцент (главное действие и главное на экране) | `--accent` `--accent-2` |
| Данные, ссылки, фокус | `--sky` |
| Смысл | `--good` (победа, плюс), `--bad` (поражение, минус), `--warn` (внимание) |
| Шрифты | `--display` Alegreya SC только для крупных заголовков и больших чисел, `--body` Jost для всего остального |
| Скругления | `--radius` 16px, `--radius-s` 10px (кнопки 12px, метки 99px) |

Правило акцента: на экране одна главная вещь (цель, главная ошибка, главный вывод). Она получает «выделенную» рамку; всё остальное спокойное. Красный и зелёный только для смысла (минус и плюс), оранжевый — для действия и внимания.

## Компоненты (классы, которые использует `app.js`)

- Карточка: `section.panel` (+ заголовок `h2`). Вложенный блок без рамки: `.sunk`, `.note`, `.howto`.
- Выделенный блок (главное на экране): `section.panel.kraft` с `h2` и `b` — цель; `.leak-focus` — главная ошибка; `.coach-focus .goal` — главная цель тренера; `.hl-tile.feature` (+ `.good` / `.bad`) — главная цифра.
- Ключевая цифра: `.hl-row > .hl-tile` с `.hl-label`, `.hl-value.num`, `.hl-sub`, `.hl-chip(.good|.bad)`. Бегущее число: `span[data-count][data-decimals][data-suffix]`.
- KPI-плитка: `.kpis > .kpi` (`.kpi-label`, `.kpi-value`, `.kpi-hint`, `.kpi-bar > span`; тон `.good` `.warn` `.bad`).
- Кнопки: `button.btn` (обычная), `.btn.primary` (одно главное действие на экран), `.btn.small`, `.btn.icon`. Иконка внутри кнопки: `Icon('arrow')`.
- Метки: `.pill` + `.good` `.warn` `.bad` `.hot` (цветные), `.pill.low` — «мало данных» (нейтральная пунктирная, без цвета результата), `.delta` `.place` — отклонение и место.
- Таблица: `table.table` (`th.sortable`, `tr.click`, `td.num`, `td.r`), герой в ячейке: `.hero-cell` + `heroIcon()`.
- Вкладки и переключатель: `.tabs > .tab(.active)`, `.seg > button(.on)`.
- Список матчей: `.match(.win|.loss)`, `.day-head`.
- Герои с артом: кнопка выбора `.hpick` (карточка героя с подсветкой цвета героя), плашка `.hero-pick`, строка `.dash-hero-row`. Данные: `style: heroArtStyle(герой)` из `app.js` (CSS-переменные `--art`, `--wide`, `--hc`). Для нового списка героев использовать этот приём, а не маленькую иконку.
- Шаги: `.step-head > .step-n + h2`, выбор героя: `.hgrid > .hpick(.on|.lane)`.
- Пустое состояние: `.empty` с `strong`; ожидание: `skeleton()`.
- Иконки: `Icon('имя')`, имена из `vendor/lucide-icons.js` (например `flame`, `lightbulb`, `refresh-cw`, `arrow-right`, `trophy`, `zap`, `target`, `swords`, `skull`, `clock`).

## Как заказать оформление

Прислать сессии редизайна описание: что за экран, какие блоки и в каком порядке, какие поля, какое из них главное, какие состояния (мало данных, ошибка, пусто, загрузка). Данные подключаются к уже готовым классам выше; новые классы добавляет только сессия редизайна. Правки общего `app.js` ведутся по очереди: сначала заявки, которые меняют разметку одного экрана, потом общие.

## Библиотека артов

Собственные арты лежат в `src/renderer/assets/art/` (генератор `tools/make-art.js`, просмотр `assets/art/index.html`): `skyline-*.svg` — силуэты города, `emblem-*.svg` — эмблемы разделов (шапка экрана берёт их через `--emblem` в theme.css), `rays-*.svg` — лучи ар-деко для главных блоков, `hex-grid.svg` и `hero-shards.svg` — подложка карточек героев, `divider-deco.svg`. В CSS доступны переменные `--art-skyline`, `--art-dawn`, `--art-teal`, `--art-rays`, `--art-hex`, `--art-shards`. Новый арт добавляется в генератор, а не рисуется вручную.

Сцены шапок: `assets/art/scene-*.svg` (по одной на раздел, свои композиции, генератор `tools/make-scenes.js`, просмотр `assets/art/scenes.html`); значки классов героев `class-*.svg`. Параллакс шапок, наклон карточек и искры на фоне: `fx.js`.

Графики: `charts-ec.js` (Apache ECharts, `vendor/echarts.min.js`) подменяет lineChart, formChart и добавляет rankChart; прежние SVG-графики в `charts.js` остаются запасными. Пустые состояния: `.empty` получает иллюстрацию по разделу (`assets/art/empty-*.svg`). Заставки героев: `.hero-banner` берёт `--art`, `--wide`, `--hc` из `heroCardStyle()`.

Герои в списках и таблицах: `heroIcon()` рисует герб героя (`crest.js`: форма по классу, цвет героя, буква), крупные портреты `.lg`/`.xl` берут арт героя. Для нового списка героев использовать `heroIcon(id)`.
