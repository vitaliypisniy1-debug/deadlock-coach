## Баннеры последнего матча на Главной (создаёт владелец)

Папка `banners/`: файлы `<имя-героя>-win.webp` и `<имя-героя>-loss.webp` (имя: английское, строчными, через дефис, например `lady-geist`, `mo-and-krill`). Их делает владелец проекта внешним инструментом генерации изображений по мотивам персонажей Deadlock; название инструмента и условия использования он не уточнял. Права на персонажей принадлежат Valve. Первые два файла: `paradox-win.webp` и `paradox-loss.webp` (получены 14.11.2026, 1860×318, прозрачное затухание слева). Новые файлы владелец кладёт в папку-приёмник `..anners-inbox` (вне репозитория) и запускает `npm run banners` (`tools/ingest-banners.js`): скрипт проверяет имя, размер и прозрачность, при необходимости пересохраняет в webp и обновляет `src/renderer/banners.js`. Если баннера для героя и результата нет, карточка показывает обычный арт героя с акцентом по результату. Используются только в верхней карточке Главной (`renderOverview`, `.dash-result-art`).
