# Пилот «Ошибок» на 10 000 матчей

Скрипты для оценки правил раздела «Ошибки» на большой выборке рейтинговых матчей deadlock-api. Результаты и выводы — в [docs/ERRORS_PILOT.md](../../docs/ERRORS_PILOT.md). Данные (около 1,6 ГБ) в Git не попадают: папка `pilot-data/` в `.gitignore`. Профиль приложения скрипты не читают и не пишут.

Папка данных — первый аргумент или переменная `DC_PILOT_DIR` (по умолчанию `tools/errors-pilot/pilot-data`). Нужен `assets.json` (каталог предметов приложения) — положить в папку данных или указать в `DC_ASSETS`.

Порядок:

1. `node tools/errors-pilot/download.js [папка]` — `N=10000` матчей за последние 2 дня (рейтинг, от 25 минут) с маршрутами; продолжает с места остановки. ~0,3 с на матч, SQL-запрос списка ограничен 2 запросами в минуту.
2. `node tools/errors-pilot/ranks.js [папка]` — ранги игроков из SQL (`player_rank_initial_display_rank`): у новых рейтинговых матчей средний значок в метаданных равен 0. Окно времени в начале файла нужно подправить под скачанные матчи.
3. `node tools/errors-pilot/features.js [папка]` — какие правила сработали у каждого игрока (`rows.jsonl`).
4. `node tools/errors-pilot/association.js [папка]` — связь правил с победой с поправкой на ранг, смерти и длину матча; необязательно `DC_ROLES_FILE`/`DC_BENCH_FILE` для разбивки по классам героев.
5. `node tools/errors-pilot/episodes.js [папка]` и `episodes-report.js` — эпизодная оценка: что происходит за 75 секунд после смерти в одиночку и в драке с фармящим вдали союзником.
6. `node tools/errors-pilot/lane.js [папка]` — разрыв по душам на линии к 10:00 и доля побед.
7. `node tools/errors-pilot/norms.js [папка]` — нормы по герою, рангу и роли, границы признаков роли → `src/core/data/errorNorms.json` (только агрегаты, без личных данных).

Выборка по времени и героям случайная (`ORDER BY hash(match_id)`), поэтому нормы описывают игроков рейтинга за ноябрь 2026 (патч 6861). После обновления игры нормы нужно пересчитать.
