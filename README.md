# Deadlock Coach

Личный тренер по Deadlock для Windows. Следит за метой топ-50 или топ-100 **текущего сезона** и учит тебя на примере этих игроков.

Меню слева разбито на две части:

**Моя игра** — всё про тебя:
- **Главная** — форма за 3–14 дней, ранг, сравнение с лобби и топами, задачи тренера и советы, над чем работать.
- **Тренер** — 2–3 цели на неделю под твои слабые места, проверка после каждой игры, график по каждой цели. Закрыл цель (4 из 5 игр) — тренер даёт следующую.
- **Мои матчи** — разбор любой игры поминутно против топов на том же герое: души по источникам и фазам, урон, смерти, тайминги предметов, миникарта. Кнопка «Бок о бок с про-игроком» ставит твой матч рядом с матчем топа на том же герое и похожей сборке.
- **Мои герои** — сводка по каждому твоему герою: что получается, что повторяется из игры в игру, против кого тяжело.

**Мета · топ-N** — что делают лучшие:
- **Мета героев** — на ком играют топы, винрейты с честной поправкой на число игр, сборки по фазам, паверспайки, неудобные соперники и что против них докупают.
- **Перед игрой** — выбираешь своего героя и соперников (второй клик — соперник на линии) и получаешь короткий план: кто опасен, кого топы обыгрывают, какие предметы докупить.
- **Про-игроки** — топ ладдера, кто что спамит, избранные игроки.

Все данные — из открытого сервиса [deadlock-api.com](https://deadlock-api.com) (не связан с Valve).

## Запуск

1. Установи **Node.js LTS** с https://nodejs.org (один раз).
2. Распакуй папку и дважды кликни **start.bat**.
   Первый запуск сам установит Electron (около минуты), дальше открывается сразу.

Вручную то же самое: `npm install`, затем `npm start`.

Готовые .exe собираются на GitHub автоматически при каждом релизе — см. **UPDATES.md**. Собрать у себя на Windows тоже можно: `npm run dist` → папка `dist`.

## Первые шаги

1. **Главная** → «Войти через Steam» (или вставь ссылку на профиль: `.../id/ник` или `.../profiles/7656...`). Пароль вводится только на сайте Steam — программа получает лишь твой Steam ID.
2. **Мета героев** → «Обновить данные». Первый сбор займёт несколько минут. Потом обновляется только новое (по умолчанию раз в 3 часа, пока программа открыта).
3. Открой **Тренер** — после 5 игр с подробными данными появится план на неделю.
4. Если только что сыгранного матча нет — в игре открой «Профиль» → «История матчей» → этот матч, затем в **Моих матчах** нажми «Найти в кэше Steam».

## Что нового в 0.9

- **Программа в .exe и обновления из программы.** Сборка установщика и переносной версии идёт на GitHub (GitHub Actions) при публикации релиза. Установленная программа сама проверяет новые версии, показывает «что нового» и обновляется кнопкой — тихая установка поверх и перезапуск, данные сохраняются. Как выпускать версии — в файле **UPDATES.md**.
- Установщик теперь в один клик и без прав администратора (ставится в папку пользователя), поэтому обновления не задают вопросов.
- Настройки → «Обновления»: текущая версия, ручная проверка, автопроверка при запуске.

## Что нового в 0.8

- **Оверлей «Пик против состава»** — окно поверх игры по горячей клавише (по умолчанию **Ctrl+Shift+D**, меняется в настройках). В рейтинге после того, как матч найден, есть пауза ~30 секунд: видны стартовые герои соперников, и можно один раз сменить своего героя. Отмечаешь соперников (клик, или начни печатать имя и Enter) — оверлей сразу говорит, кого брать из твоих героев, или что лучше остаться. Правый клик — союзник (его героя взять нельзя), Shift+клик — твой текущий герой.
- Оценка героя = матчапы против каждого соперника (твои игры ×2 + игры топового уровня, каждый матчап максимум ±15) + твой опыт на герое + немного меты. Таблицы для твоих героев считаются заранее в фоне, поэтому в паузе всё мгновенно.
- «Мои герои для рейтинга»: по умолчанию герои с 15+ победами (столько нужно для рейтинга), можно выбрать вручную в настройках.
- Оверлей видно поверх игры в режиме «В окне без рамки» (Borderless). Игру он не трогает: не читает память и не меняет файлы.
- Эксперимент «Проверить лог игры»: если добавить в параметры запуска Deadlock `-condebug`, игра пишет лог консоли — программа покажет, есть ли в нём герои матча (для будущего автоматического распознавания состава).

## Что нового в 0.7

- **Выгрузка билда из любой игры.** В разборе своего матча — кнопка «Выгрузить билд»; в окне любого матча — у каждого игрока своя кнопка. Билд: прокачка способностей по очкам + предметы по стадиям (как в игровом редакторе: до 10:00, 10–20, 20+) + что было к концу игры. Можно скопировать текстом (для Discord), скопировать или сохранить картинкой, сохранить .txt или .json. Там же — самые похожие опубликованные билды: их можно найти в игре (B → Browse Builds → Public → поиск по названию). Загрузить билд прямо в игру сторонняя программа не может: билды хранятся на серверах Valve.
- **Скилл-билд.** Таблица «какое очко в какую способность»: у топов на странице героя в мете (самый частый путь прокачки, что максят первым, когда открывают ульту), у тебя — в «Моих героях» рядом с топами, с подсказкой, если твой порядок отличается.

- Свой загрузчик Electron в `start.bat` (новые версии npm не запускают установочный скрипт Electron).

## Что нового в 0.2

- **Несколько сборок на героя.** Игры топов делятся на группы с похожим набором предметов (например, «через оружие» и «через спирит»). У каждой — свой винрейт, число игр, предметы, которые её отличают, и паверспайки.
- **Паверспайки с цифрами.** Урон по героям в минуту за 3 минуты до и после покупки, насколько это сильнее обычного роста, и в скольких играх сразу была драка.
- **Лагерь сравнивает с твоей сборкой.** Сначала определяется, какую сборку ты играл, и сравнение идёт с топами на ней же — за другую сборку программа не ругает. Добавлены блоки «Главное в этой игре» (3 пункта с советами), «По фазам игры» и «Паверспайки твоей сборки».

- **Карточка игрока.** Во вкладке «Игроки» — последние матчи каждого топа с предметами и пометка «спамит героя», если один герой занимает половину и больше его последних 20 игр.

## Что важно знать

- **Импорт билда.** Записать билд прямо в игру сторонняя программа не может: билды хранятся на серверах Valve. Поэтому программа ищет самый похожий *опубликованный* билд — в игре: магазин (B) → Browse Builds → Public → поиск по названию → сердечко. Плюс можно скопировать чек-лист с таймингами.
- **Аккаунты топов.** Ладдер показывает только ник. Если у ника несколько аккаунтов, берётся тот, кто играл последним (пометка «угадан»). Ошибку можно поправить вручную во вкладке «Игроки».
- **Не все матчи есть в API.** Часть игр сервис не успевает собрать. Кнопка «Найти матчи в кэше Steam» отправляет в сервис твои матчи из кэша Steam (так же работает официальная утилита сбора).
- **Точность по времени.** Статистика в матче записывается снимками с интервалом в несколько минут, между ними значения достраиваются линейно. Для ответа «где я отстаю» этого хватает; посекундный разбор возможен только через файлы реплеев.
- **Мало игр = ненадёжно.** У редких героев за 3 дня бывает 3–5 игр топов. Такие строки помечены «мало игр», а полоска в столбце «Винрейт» показывает реальный разброс.

## Настройки

Регион ладдера, сколько топов брать, период (1–14 дней), только рейтинговые матчи, с кем сравнивать (только топы или все игроки в их матчах — данных больше), только победы, автообновление, ключ deadlock-api (необязателен, с ним выше лимиты — бесплатно выдают в Discord проекта).

Данные хранятся в `%APPDATA%\Deadlock Coach\data` — обычные JSON-файлы. Матчи топов старше 14 дней удаляются, твои — никогда.
