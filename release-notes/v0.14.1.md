**Безопасность обновлений**
- Перед запуском установщика программа проверяет SHA-256 по контрольной сумме, которую GitHub публикует для файла релиза.
- Если GitHub не отдал контрольную сумму или файл повреждён при скачивании, обновление останавливается, скачанный файл удаляется, а запуск блокируется.
