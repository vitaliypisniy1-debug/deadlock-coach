# Как выпускать обновления Deadlock Coach

Программа собирается в .exe на серверах GitHub, а установленные копии сами предлагают обновиться. Собирать что-то у себя на компьютере не нужно.

## Один раз: выложить код на GitHub

**Способ 1 — проще всего.** Подключи GitHub к Claude: claude.ai → Настройки → Коннекторы → GitHub. Дальше Claude сам создаёт репозиторий, выкладывает код и выпускает версии.

**Способ 2 — вручную через сайт.**
1. github.com → «+» справа сверху → **New repository**. Название `deadlock-coach`, **Public**, галочки «Add a README» не ставь → **Create repository**.
2. На странице репозитория нажми ссылку **uploading an existing file**.
3. Перетащи в окно **всё содержимое** папки программы, кроме `node_modules` и `dist`. Обязательно вместе с папкой `.github` — в ней сборка.
4. Внизу **Commit changes**.

## Каждый раз: выпустить новую версию

**Если GitHub подключён к Claude** — просто скажи «выпусти версию». Claude обновит код, запишет «что нового» в `release-notes/vX.Y.Z.md` и отправит тег — GitHub сам создаст релиз и соберёт .exe.

**Вручную через сайт:**

1. Обнови файлы в репозитории (Claude присылает новый архив, а если GitHub подключён — делает это сам).
2. На странице репозитория: **Releases** (справа) → **Draft a new release**.
3. **Choose a tag** → впиши номер новой версии, например `v0.9.1` → «Create new tag».
4. Название — например `Deadlock Coach 0.9.1`. В описание напиши, что нового, по пункту на строку, начиная с «-». Этот текст увидят в окне обновления.
5. **Publish release**.

Через 5–10 минут GitHub соберёт программу и прикрепит к релизу два файла:
- `DeadlockCoach-Setup-0.9.1.exe` — установщик;
- `DeadlockCoach-Portable-0.9.1.exe` — переносная версия.

Ход сборки видно во вкладке **Actions**: зелёная галочка — готово, красный крестик — ошибка (пришли Claude скриншот).

Номер версии всегда должен быть больше предыдущего: `v0.9.1` после `v0.9.0`, потом `v0.9.2` или `v0.10.0`.

## Что видят пользователи

- Установленная программа через 15 секунд после запуска проверяет GitHub. Если есть новая версия — справа внизу появляется окно «Вышла версия …» с описанием. Кнопка **Обновить** скачивает установщик, **Перезапустить и обновить** ставит его поверх. Вход, матчи и собранная мета сохраняются.
- Переносная версия и запуск через `start.bat` показывают ссылку на страницу релиза — там нужно скачать новый файл вручную.
- Проверить вручную или выключить автопроверку: Настройки → «Обновления».

## Первая установка и Windows SmartScreen

У программы нет платной цифровой подписи, поэтому при первом запуске установщика Windows может показать «Система Windows защитила ваш компьютер». Нажми **Подробнее** → **Выполнить в любом случае**. Обновления потом ставятся без этого окна.
