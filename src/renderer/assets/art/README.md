## Баннеры последнего матча на Главной (создаёт владелец)

Папка `banners/`: файлы `<имя-героя>-win.webp` и `<имя-героя>-loss.webp` (имя: английское, строчными, через дефис, например `lady-geist`, `mo-krill`). Их делает владелец проекта внешним инструментом генерации изображений по мотивам персонажей Deadlock; название инструмента и условия использования он не уточнял. Права на персонажей принадлежат Valve. Все 44 героя (победа и поражение, 88 файлов) получены 14.11.2026 из папки генератора картинок `deadlock-coach-art/outputs/deadlock-welcome-art` (имена вида `paradox-welcome-win-scene.png`, 1860×318, прозрачное затухание слева); приём пересохранил их в webp (общий вес 6,4 МБ вместо около 115 МБ PNG). Ранее присланные владельцем webp для Paradox заменены этими. Новые файлы владелец кладёт в папку-приёмник ``..\banners-inbox`` (вне репозитория) и запускает `npm run banners` (`tools/ingest-banners.js`): скрипт проверяет имя, размер и прозрачность, при необходимости пересохраняет в webp и обновляет `src/renderer/banners.js`. Если баннера для героя и результата нет, карточка показывает обычный арт героя с акцентом по результату. Используются только в верхней карточке Главной (`renderOverview`, `.dash-result-art`).

## Мини-портреты героев для списков на Главной (создаёт владелец)

Папка `portraits/`: файлы `<имя-героя>.webp` (имя: английское, строчными, через дефис, например `drifter`, `mo-krill`, `the-doorman`). Их делает владелец проекта внешним инструментом генерации изображений по мотивам персонажей Deadlock; название инструмента и условия использования он не уточнял. Права на персонажей принадлежат Valve. Все 44 героя получены 15.11.2026 из папки генератора `deadlock-coach-art/outputs/deadlock-mini-portraits` (PNG 256×256, без прозрачности); приём уменьшил их до 192×192 и пересохранил в webp (общий вес 336 КБ вместо 6,2 МБ). Приём: `npm run portraits -- --inbox "путь к папке"` (`tools/ingest-portraits.js`): скрипт сверяет имя файла со списком героев, проверяет размер и пропорцию и обновляет `src/renderer/portraits.js` — список по ID героя (ID и имена берутся из `src/core/data/codexData.json`). Используются в блоках «Мои герои за неделю» и «Последние матчи» на Главной (`heroMini()` в `app.js`, класс `.hero-ico.mini`): картинка вписывается в рамку с обрезкой по центру, без растягивания. Если портрета для героя нет, показывается обычный арт героя из справочника игры.
