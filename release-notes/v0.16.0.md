# Deadlock Coach 0.16.0

## Справочник контрпиков и контрпредметов

- **Новый раздел «Справочник контрпиков»** (меню «Мета»): выбираешь героя соперника — получаешь два ответа. Кого взять против него до игры и что докупить, если матч уже идёт.
- **Кого взять**: таблица героев с их результатом против выбранного соперника минус их обычный винрейт в той же выборке — сильный сам по себе герой не выглядит «контрпиком» против всех. Отдельно показан результат на одной линии и разница душ к 9-й минуте.
- **Что купить**: предметы, которые топы в реальных матчах берут против этого героя заметно чаще обычного, плюс ответы из проверенных механик — чем опасен герой, что снижает его лечение, что сокращает его эффекты.
- **Из моего пула**: фильтр по героям, на которых ты играешь (нужен вход через Steam).

## Честность выводов

- У каждой рекомендации виден источник: статистика матчапов (Deadlock API, все матчи выбранного ранга за 14 дней), покупки топов (lift против игр без этого героя) или механика из файлов игры (deadlock.gs, патч Halloween, build 6861).
- Пары с малым числом игр скрыты, скромные выборки помечены «мало игр», преимущество конкретной пары обычно невелико (около ±1 п.п.) — это написано прямо в разделе.
- Если явных контрпиков или покупок нет, раздел честно говорит, каких данных не хватает, а не подставляет универсальные советы.
- Механики героев разобраны пока не для всех: Apollo, Victor, Lash и Infernus — с полными правилами (чем опасен, чем лечится, что против него), остальные — по статистике и покупкам. Список будет расширяться после каждого патча.
- Ответ кэшируется по герою: смена соперника не запускает новых запросов к сети. При сбое сети показываются сохранённые данные с датой и ошибкой обновления.

## Входы из других разделов

- «Мета героев» → страница героя → «Кого взять против него».
- «Перед игрой» → выбери соперника → «Справочник по сопернику».

Формат хранения матчей не менялся: история, статистика и цели тренера сохраняются, перекачка не нужна.
