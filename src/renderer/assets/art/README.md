# Происхождение артов

## Нарисованы кодом (`tools/make-art.js`, `tools/make-scenes.js`)
`skyline-*.svg`, `scene-*.svg`, `emblem-*.svg`, `empty-*.svg`, `class-*.svg`, `rays-*.svg`, `hex-grid.svg`, `hero-shards.svg`, `divider-deco.svg`, `noise.svg`. Собственная работа проекта, чужих материалов нет. Просмотр: `index.html`, `scenes.html`.

## Баннеры последнего матча на Главной (предоставлены владельцем)
- `last-win-paradox.webp` (победа: фигура с поднятой рукой и золотым кольцом над городом);
- `last-loss-paradox.webp` (поражение: фигура под дождём, разбитое стекло).

Файлы 1860×318 с прозрачным затуханием слева положил в проект владелец (14.11.2026). По виду это сгенерированные изображения по мотивам героя Paradox из Deadlock, внешний инструмент и условия использования владелец не уточнял. Права на персонажа принадлежат Valve. Используются только в карточке приветствия на Главной (`renderOverview`, `.dash-result-art`), когда героем последнего матча был Paradox. Для других героев карточка показывает обычный арт героя из справочника игры с зелёным или красным акцентом по результату.

## Арты героев из справочника игры (не хранятся в проекте)
Поля `card`, `wide`, `img` из `assets.json` (публичный Deadlock API, `assets-bucket.deadlock-api.com`), показываются по ссылке, как и прежние иконки.
